# chevrecheese portfolio

Personal portfolio site for [chevrecheese.space](https://chevrecheese.space).

## Stack

- Vite + React + React Router
- GitHub Pages (deployed via GitHub Actions)

## Local development

```bash
npm install
npm run setup-assets   # copy images/videos from source folders into public/assets/
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` trigger `.github/workflows/deploy.yml`, which builds and publishes to GitHub Pages.

### Custom domain (Spaceship DNS)

| Type  | Host | Value |
|-------|------|-------|
| A     | `@`  | `185.199.108.153` |
| A     | `@`  | `185.199.109.153` |
| A     | `@`  | `185.199.110.153` |
| A     | `@`  | `185.199.111.153` |
| CNAME | `www` | `chevrecheese.github.io` |

In GitHub repo **Settings → Pages**, set custom domain to `chevrecheese.space` and enable HTTPS.

## Project structure

- `src/` — React app
- `public/assets/` — web-ready images and videos (generated by `scripts/setup-assets.sh`)
- `design/`, `s.creme/`, `chainmaille/`, `about/` — original source content and reference files
